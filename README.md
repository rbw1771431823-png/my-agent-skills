# My Agent Skills｜项目记录与任务分工

让 AI 记清项目决定，并把任务交给合适的角色。

两份可单独安装、也可配合使用的 Agent Skill。适合需要持续记录、跨会话接手、多人或多 Agent 协作的项目；不固定模型品牌或 Agent 身份。

[English](README.en.md) · [安装与首次设置](docs/INSTALL.md) · [使用示例](docs/EXAMPLES.md) · [兼容与验证范围](docs/COMPATIBILITY.md) · [更新记录](CHANGELOG.md)

## 包含什么

| Skill | 什么时候用 | 它会做什么 |
|---|---|---|
| [项目记录员](skills/project-records-steward/SKILL.md) `project-records-steward` | 查历史决定、同步已确认变化、整理项目导航 | 核对原始依据与新旧关系，在授权位置更新记录，保留历史、冲突和未完项；附目录生成与检查工具 |
| [按任务分工](skills/cost-aware-delegation/SKILL.md) `cost-aware-delegation` | 接手任务、恢复工作、选择直接处理或委派、安排复核 | 根据任务边界选择分工，交清资料、写权与验收，核对进度，避免重复派遣和重复执行 |

记录员可以独立使用。分工技能也不要求先安装记录员：已有可靠记录方式时继续沿用。

## 快速开始

将本仓库地址或下载解压后的文件夹交给目标平台的 Agent，并发送：

```text
请安装这里的 project-records-steward 和 cost-aware-delegation 两份 Skill，
保留各自完整文件夹。读取 SKILL.md 和首次设置说明，
先复用已有设置，只询问当前确实缺失的选择。
安装本身不要启动项目工作、创建分身或生成项目目录。
最后分别说明：已安装什么、首次设置是否完成、还有哪些能力未验证。
```

安装目录由目标平台确认，不照抄其他电脑的路径。也可只选一份安装。[完整安装说明](docs/INSTALL.md)

有些安装器只复制文件，不会当场提问；这种情况下，首次实际使用会按 Skill 指令补齐必要设置。设置是否跨会话自动加载，取决于平台是否会读取所选入口。[具体边界](docs/COMPATIBILITY.md)

## 安装后可以这样用

**查决定：**

```text
请用项目记录员查清：目前活动安排以哪份文件为准？
只读查询，给出依据；如果资料冲突，不要替我选择。
```

**同步变化：**

```text
已确认：活动开始时间由9点改为10点，地点不变。
请按项目现有记录规则同步，保留旧决定及替代关系，列出尚未完成的检查。
```

**安排工作：**

```text
请用按任务分工接手这个已授权任务。
先核对已有进度，选择直接处理还是委派，说明资料、写权、验收与回报方式。
不要重新派出已完成或仍在进行的工作。
```

## 首次需要设置什么

Agent 先检查当前能力和已有约定；只有影响当前任务的缺项才询问，例如：

- 哪份资料是现行依据，哪些位置允许更新。
- 是否允许委派；确实需要分身时，沿用平台默认还是使用用户选定的配置。
- 设置保存在哪里，后续如何找到；是否需要维护项目目录导航。

这些答案保存在使用方，不写回可分发 Skill。以后复用已有决定；换平台或能力变化时只重核受影响项。

## 兼容与限制

| 部分 | 需要什么 | 当前验证情况 |
|---|---|---|
| 记录、查证与分工方法 | Agent 能读取 Skill 和所需资料 | 已做本机隔离行为试用及独立复核；其他 Agent 平台尚未实机验证 |
| 实际保存项目记录 | 文件写入能力及对应授权 | 已验证隔离文件的保存、读回和只读续用 |
| 委派与独立复核 | 平台提供对应能力，且任务允许 | 缺少分身能力时可直接处理适合的工作；自查不能算独立复核 |
| 随附目录脚本 | 命令执行能力、PowerShell 及项目写权 | Windows 普通路径已验证；PowerShell 7通过深层样例，旧版5.1有长路径限制；其他系统未验证 |

可选的 `agents/openai.yaml` 供兼容产品显示和发现 Skill；其他平台可忽略。Skill 不会为平台补出原本没有的工具、权限或模型。

分工方法以质量为前提，不承诺每个任务的 Token、费用或耗时都会下降。目录检查通过只代表导航一致，不能代替项目内容或功能验收。
