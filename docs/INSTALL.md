# 安装、首次设置与更新

本仓库使用 [Agent Skills](https://agentskills.io/specification) 的文件夹形式。两份 Skill 都可以单独安装；无需先安装另一份。

## 让 Agent 安装

把仓库地址或解压后的仓库文件夹交给目标平台的 Agent，复制下面这段：

```text
请从这个仓库安装 project-records-steward 和 cost-aware-delegation。
先确认本平台实际支持的个人技能位置，保留每份完整文件夹及 LICENSE。
如果已有同名版本，先比较并备份本机修改，不直接覆盖未知修改。
读取每份 SKILL.md 和 references/first-use-setup.md，按其中流程完成当前所需设置。
先复用我已确认的选择，只询问确实缺失的资料、写权或运行偏好。
个人和项目设置保存到使用方的授权位置，不写回这两份 Skill。
安装不要启动业务、创建分身、生成项目目录或安装额外软件。
完成后分别报告安装结果、首次设置状态和实际已验证的能力。
```

只需要一份时，在请求中保留该 Skill 名称即可。

## 手动复制

1. 获取仓库文件并解压。
2. 按目标平台的说明确认 Skill 安装目录，或让 Agent 查明；个人范围与单项目范围按自己的需求选择。
3. 把 `skills/project-records-steward` 或 `skills/cost-aware-delegation` 整个文件夹复制进去，不要只复制 `SKILL.md`。检查其 `references`、`scripts`、`assets`、可选元数据和 `LICENSE` 是否完整；不同 Skill 所含子目录不同。
4. 让目标 Agent 实际读取安装后的 `SKILL.md`。平台未显示新 Skill 时，按该平台的重载说明处理。
5. 第一次处理任务时，沿首次设置说明补齐必要选择，再核对一个小型实际任务。

本包不依赖某个通用命令行安装器，也不提供插件市场安装命令。支持仓库目录安装的工具，可以分别选择上述两个目录；具体参数以工具自己的说明为准。

## 首次会问什么

Agent 应先读现有约定、检查当前所需能力，然后只问缺项。可能涉及现行资料与写权、委派方式及可用配置、设置保存位置，以及确实需要目录导航时的根目录和排除范围。

只查询历史时，不为未用到的分身或目录功能追问设置。已有有效配置直接沿用；安装器只复制文件时，由首次使用补接。Skill 没有保证所有平台都会执行的安装后自动钩子。

答案保存在使用方的既有个人设置或项目协作入口。另存设置文件时，需要一个平台会读取的入口指向它；没有可靠入口时应说明如何手动提供，不能称为已自动持久生效。两份 Skill 可复用同一份设置。

## 目录工具

一般记录和查询不需要 PowerShell。只有运行记录员附带的目录生成与检查脚本时，才需要相应命令环境及项目写权。

安装 Skill 本身不授权扫描项目、生成目录或创建业务骨架。缺少运行环境时，不自动安装；先说明受影响动作与可继续部分。具体调用见 [目录维护说明](../skills/project-records-steward/references/directory-maintenance.md)。

## 更新与迁移

更新前比较已安装文件和新版本；保留本机修改与原配置的可恢复副本。更新后核对新增引用、许可证及受影响设置，不把文件覆盖成功称为业务验收通过。

新平台不直接继承旧平台的模型名称、工具接口、机器路径或临时 Agent 编号。需要改变选择时，只重核受影响项。换电脑也不代表本机安装会自动同步。

## 简单确认是否装好

让 Agent 查一个有明确依据的小问题，只读回答并给出来源。再在获准的隔离文件里验证一次局部更新，核对旧资料保留、写入位置正确及结果可读。

把“文件已安装”“设置已保存且入口可读”“实际任务已验证”分别说明。不要用一次成功推断所有平台和任务都已兼容。[已验证范围](COMPATIBILITY.md)
