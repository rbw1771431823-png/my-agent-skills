# 按平台接入

只在需要把已确认设置映射到当前平台的真实操作时读。通用规则不依赖本页中的某个产品；本页不提供新权限。先看当前环境实际暴露的工具/文档，不猜测其他产品的接口或安装路径。

- 有原生分身/子任务工具：按真实参数交包、续接及取回结果；模型、推理档位和上下文选项采用首次设置或已有项目决定。不支持某个选项就报告，不伪造支持。
- 只有单Agent：当前Agent在已有写权内承担记录，按执行手册核查；独立复核要求仍须独立人员或可用角色完成。只有聊天、没有文件工具时只交待写内容。
- 平台只支持文字Skill：从SKILL.md及相对引用读流程；按它的公开说明安装。目录脚本另需可执行命令及PowerShell；不能把读懂规则说成脚本已运行。

## Codex的可选接法

仅当当前环境实际暴露且允许使用`collaboration.spawn_agent`时，以其真实`model`、`reasoning_effort`、`fork_turns`等可用字段表达已确认选择；没有某个字段/选项时遵循当前工具说明。需要不继承历史的任务可请求`fork_turns="none"`，仍须核对实际上下文边界。续接使用本环境支持的工具与已核实任务绑定，不依赖固定AgentID。

随附`agents/openai.yaml`仅供兼容产品设置界面显示和发现策略；它不设置运行模型，也不执行首次询问。其他平台可忽略此可选文件，不影响通用正文。当前安装位置以该平台文档与实际环境为准，不复制作者机器路径。
