# 恢复、接管与异常交接

常规派遣/复核已在SKILL.md；仅恢复、换人、接管或交接异常时读本页。

- 核对项目绑定、当前任务、实际文件/版本、未完批次及文件写权，不能凭旧ID或压缩摘要断定仍可接续。有任务才恢复可用记录员；确需新建才查[配置](runtime.md)。首次绑定提供技能/项目映射、任务与工作区、明确写权；连续批次沿用已核实绑定。
- 记录员较慢先查阻碍或缩小本批范围，不因一次等待就中断重做。接管前明确交回/撤销写权，确认运行中工具结束并核对已写内容，防止迟到写入；不频繁轮询。
- 缺原话或指代不清，补齐所指问题/选项和修正；只有聊天中的证据须直接传相关完整片段或存原任务，不能假定记录员看得到父线程。长上下文按议题给可读来源，不截掉条件。跨文件搜索仍由记录员做。
- 回执矛盾、证据不足、重要删除/范围变化或抽查异常时，定向打开完整依据；必要检查未完成不能交付通过。可继续无依赖讨论，依赖新记录的操作须等关键落盘。
- 规则迁移不打断已有批次；交权后在下一正式包提示读取新版。临时由主理人执行时先说明，不假称分身收到消息。
