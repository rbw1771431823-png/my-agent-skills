# 项目接入

仅首次接入、迁移或项目结构改变时读。安装/首次运行按[首次设置](first-use-setup.md)复用或补齐平台设置；制作/安装技能不自动授权改项目。

在该平台实际读取的现有项目指令或协作说明登记：接手入口、唯一状态/决定/方案位置、历史证据、原任务批次/回执位置、主理人独占与可分配写权、项目检查/交付规则。沿用已有文件名，不强制名为AGENTS.md。不另建状态库，不给未用Git/TASK的项目强加机制，不将具体项目路径和议程写进通用技能。

接手指引要求主理人亲读当前定位与映射，再读SKILL常规卡；附页按其触发条件读，不再默认追加交接全文。记录员另读执行手册。找不到Skill应报告，可从已保存的交付快照恢复，不假称加载。

迁移前查旧规则及引用：通用程序归Skill，项目只留映射/特例；移除重复正文及失效阅读要求，保留必要锚点和可恢复历史。模型偏好、权限及未完批次不能因精简丢失。已有批次的交接按[恢复/接管规则](task-handoff.md)处理，不将文件更新说成记录员已加载。

首次采用目录导航时，确认项目选定的根目录、现有目录约定和允许写入范围。已有导航按项目约定复用；没有导航时，仅在任务或项目规则明确要求后，从选定根目录生成，不自动补项目骨架，也不因安装Skill扫描其他项目。项目名称、状态、描述、优先级和排除项放项目侧目录配置；通用Skill不保存项目事实。目录更新/检查流程见[目录维护说明](directory-maintenance.md)，仅在需要自定义项目语义时查看[项目目录配置](directory-profile.md)。

先核对短卡可独立派遣、执行手册保留核查与判重、引用不冲突。后续获授权的真实批次观察是否实际委派写入、漏记/旧口径残留或频繁接管；简要留原任务。静态字符数不等于Token或实际节省，不另造永久指标库。
