# 目录导航维护

只在本次任务或项目规则授权的项目根目录运行目录工具。它负责列出文件和文件夹，便于找到资料；它不判断资料事实是否正确。

## 何时更新

- 项目已经有目录导航，而且本项目规则或本次任务授权记录员维护目录时：更新后立即检查，不重复向用户索要确认。
- 只查历史、决定或资料时：保持只读，不运行更新。
- 新项目没有目录导航时：仅当本次任务或项目规则明确要求接入目录导航，才从用户指定的项目根目录生成。工具只为现有目录写导航文件，不建立业务文件夹、编号目录、Git仓库或TASK。
- 安装或复制Skill本身不授权扫描或修改任何项目。一次接入只作用于本次指定项目，不顺手发现和改动其他项目。

## 运行

先检查当前平台能否执行命令、项目写权与PowerShell是否可用。首次尚未决定的目录根、排除范围或运行环境按[首次设置](first-use-setup.md)询问；已有明确授权不重复问。缺少PowerShell只影响随附目录脚本，不妨碍一般记录/查询；可按原约定人工维护导航并说明，不能假称脚本检查通过。安装运行环境须另有授权，不自动安装。

从已解压的Skill目录运行，或由项目现有兼容入口调用：

~~~powershell
pwsh -NoProfile -File "./project-records-steward/scripts/update-directory.ps1" -Root "./目标项目"
pwsh -NoProfile -File "./project-records-steward/scripts/check-directory.ps1" -Root "./目标项目"
~~~

示例使用PowerShell 7的pwsh；Windows有旧版PowerShell时也可用powershell替代，深层长路径限制见本页末尾。PowerShell是运行这些脚本的命令环境；这项依赖与Agent品牌无关，其他系统仍需实际验证。Root表示本次项目所在文件夹，省略时使用当前目录；由Agent替换为当前环境确认的真实根目录，不照抄范例。ProjectProfilePath是项目自己的JSON设置文件路径，里面保存名称、状态和说明；不传配置就用通用默认说明。在有写入权限的项目文件夹运行即可，通常不需要管理员权限。

更新工具只创建或改写目录导航文件，不删除、移动或改名输入。没有变化时不重写文件、不刷新时间戳；有内容变化时才更新“最近同步”时间。空文件夹继续保留，不据此推断它是垃圾。

遇到链接文件夹（快捷入口、联接或目录符号链接）会报告路径并停止跨越，避免把项目根外内容读入清单。普通文件链接不递归进入。

## 目录规则

- 每一页只列当前文件夹的直接子项，不展开更深层内容；先列文件夹，再按名称列文件。
- 子文件夹链接到它自己的目录文件。文件链接到文件本身；链接名中的百分号、井号等按网页链接规则转义。
- 目录包含用途、打开时机、父级链接、直接子项表、更新时间和条目数，并写入机器可核对的名称清单。
- 空目录显示为空目录，导航工具不会删除它。
- 默认跳过常见版本管理、开发环境和缓存目录：.git、.codex、.agents、__pycache__、node_modules、.venv、.cache，以及.pyc文件。.local是否属于本项目的私有缓存由项目配置决定；项目可追加排除目录、名称模式或文件扩展名，具体项目排除项不进入通用Skill。
- 项目自己的名称、目录用途、状态、优先顺序、文件说明和打开时机由项目配置保存。通用Skill只提供读取这些设置的机制。

## 检查内容

检查工具会报告缺少目录文件、格式标记错误、清单漏项或过期项、重复或损坏的清单标记、缺少子目录导航、错误的目录链接目标，以及项目配置指定的未完成说明。项目配置格式有误时，更新工具在写入任何目录前报告配置路径和原因。

“检查通过”只表示目录清单与当前文件名/链接相符，不表示资料内容、研究判断或项目功能已经验收。完整目录约定和项目配置字段见[项目目录配置](directory-profile.md)。

## 可选的旧入口接法

新项目解压本Skill包后直接使用 scripts 中的更新和检查工具，不需要源项目目录或包装入口。已有项目若要保留原来的操作方式，可以由项目侧包装脚本在其旧入口继续调用这些通用脚本，并传入该项目自己的JSON配置；包装脚本属于该项目，不随本Skill包提供或强制要求。

若项目包装脚本从ZIP取出通用文件，应只将 project-records-steward 目录解到本项目的本机临时缓存，并拒绝越界路径或链接缓存目录，避免替换项目原件。缓存路径和排除规则由项目侧决定。

此版本已在Windows PowerShell 5.1（Windows旧版运行环境）和PowerShell 7（较新版本）实测普通目录与兼容入口。PowerShell 7在完整深层目录样例通过；Windows PowerShell 5.1在隔离长路径样例中报错，未通过该深层样例。遇到类似深层路径请使用PowerShell 7；其他操作系统尚未验证。
