# 记录员运行配置

仅新建、替换或核查配置时读。先复用当前用户/项目已确认且仍受支持的设置；缺少影响本次执行的设置时按[首次设置](first-use-setup.md)查明并询问。通用Skill不指定模型品牌、推理档位或固定Agent身份。

需要独立记录员时，用目标平台实际提供且允许使用的委派/续接工具，传可读的技能位置、项目映射、本批完整依据、任务与写权。模型、推理设置、上下文隔离和并发仅使用该平台支持且已确认的选项；需要具体接法时读[平台适配](platform-adapters.md)。未回显实际配置只记录请求值与未知项，不声称已独立核实。续接沿原已核实配置，不静默换档。

可接续就复用，无任务不创建。角色长期存在不等于进程常驻或自动监听；临时ID留当批任务，不写死进通用Skill或项目入口。跨项目分别绑定事实与写权。遵守当前环境/用户的委派禁令，不因Skill偏好而启动被禁止的分身。

没有委派能力或用户禁用时，当前Agent可在原授权内临时承担记录，先说明并读执行手册；没有文件读取/写入能力时报告受影响动作，可交待写内容但不称已落盘。本人检查不能称为独立复核；项目要求独立角色的环节保留待办，不阻止无依赖部分继续。
