# 项目文档记录员

首次安装时由安装Agent读取[首次设置](references/first-use-setup.md)；安装器只复制文件时，在第一次实际使用补做。已有有效设置直接复用，换平台或能力变化只核受影响项。只读查询不为初始化写文件，也不追问尚未用到的模型/目录设置。

## 主理人常规卡

亲读项目当前定位及路径/权限映射。主理人指本次任务的协调/验收责任人，记录员指承担查询或记录工作的角色，不固定平台、模型或Agent身份。主理人是唯一正式更新入口；已有可靠依据不重复查询。历史查询与更新均属记录员职责：需委派时复用已核实绑定，确需新建或改配置则先读[配置](references/runtime.md)，使用本环境真实支持且已选定的设置，不套用其他平台默认配置。

- 查询：给问题、线索、只读范围；回结论、依据、缺口。
- 更新：给唯一批次、概要/类别、完整相关问答或可读位置（问题/选项、回答、约束、修正）、已知替代关系/停点变化、文件单写权。原文片段逐一放入标注发言人/阶段的独立引用块；转述/判断另区，不整包混传；不明来源归转述。记录员执行检索、写入、检查；连续批次只补变化。
- 决定、成果、停点、冲突或交接时发包；未完项留原任务，关键落盘后才转题/宣布同步。
- 复核简报、关键差异及影响含义的原文，核对替代关系、冲突/未完项和检查证据，再依项目规则集成。完整依据按需查，不重做整批检索；收到、落盘、复核分别表达。

## 按需读取

记录员读[执行手册](references/steward-runbook.md)；主理人恢复/接管读[交接](references/task-handoff.md)，首次接入读[接入](references/project-setup.md)。用户禁用分身或工具不可用时，声明临时执行并读手册。

## 目录导航

- 已有项目规则要求维护目录，或本次任务已明确授予该项目目录维护权时，自动运行目录更新和检查；不为这一项重复索要确认。只问历史、查决定或做只读核验时，不写目录。
- 安装Skill、找到项目资料或处理一个项目，不表示可以扫描或修改其他项目。新项目没有目录导航时，只有本次任务或项目规则明确要求接入后，才从指定项目根目录生成；不创建编号目录骨架，也不要求Git或TASK。
- 需要维护目录时按需读[目录维护说明](references/directory-maintenance.md)；首次接入或调整项目专属目录语义时，再读[项目目录配置](references/directory-profile.md)。项目名称、状态、优先顺序和描述保留在项目自己的配置，不放入本通用Skill。
