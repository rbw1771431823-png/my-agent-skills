# 运行配置

用户/项目最新已确认且仍受支持的配置优先；主理人保持当前运行配置，执行与复核不预设模型品牌或档位。缺少影响本次委派的设置时按[首次设置](first-use-setup.md)处理。遵守禁派、并发和文件单写权。

使用当前平台真实提供的创建、发送任务、续接和读取结果能力；显式传入该平台支持且已选定的模型、推理设置与上下文选项。工具名和字段不跨平台照搬，具体接法按需读[平台适配](platform-adapters.md)。未回显实际配置时写清请求值与“实际未核实”；只按授权查对应回执/会话元数据，不查无关会话或解密。

配置/权限不可用须报告，仅暂停依赖它的动作，按用户允许方式处理，不静默换档；升级由主理人判断并留原因及成本。没有委派能力或用户禁派时，原授权内可直接完成适合当前Agent的工作并说明；原任务必须独立复核的部分保留待办，不能把自查冒作独立复核，也不为替代配置自动购买服务或安装软件。

同任务先核实运行状态，再复用已核实绑定；换任务只给必要资料，ID留原任务，不写死进Skill。上下文隔离能力和实际受限情况如实记录；请求新上下文不等于已证明完全隔离。配置不扩大开发、收费调用或再委派权限。
