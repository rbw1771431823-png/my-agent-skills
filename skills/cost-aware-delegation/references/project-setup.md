# 接入与迁移

确认Skill可发现/读取；安装或首次使用按[首次设置](first-use-setup.md)复用/补齐配置。在该平台实际读取的现有用户/项目指令或协作说明只加入口，不复制正文，也不强制文件名为AGENTS.md：

> 接手已授权任务、恢复或安排独立复核时，读取`cost-aware-delegation`选择分工，沿原任务进度续接；路径、写权和验收沿用现有项目映射。

沿用现有映射，只补任务记录、必要资料、写权、验收及记录员入口的缺项；不强加TASK编号或新看板。确认用户配置、工具可用性，保留授权边界。

平台/机器设置留使用方，项目路径与权限留项目；不把个人模型偏好、真实绝对路径或临时AgentID写回可分发Skill。两份Skill都在时可复用同一份设置，不要求安装其他Skill。

用未点名Skill的普通请求检查实际读取、配置和产物，覆盖小任务、禁派和恢复；显式调用成功不等于自动触发，不保证长期全对。

在同一入口更新/撤回；个人安装用于运行，版本库快照用于恢复/追溯。改为直接执行仍须续接未完任务和必要验收，保留历史结果。
