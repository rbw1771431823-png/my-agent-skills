# 按任务分工

首次安装时由安装Agent读取[首次设置](references/first-use-setup.md)；安装器只复制文件时，在第一次实际使用补做。已有有效设置直接复用，换平台或能力变化只核受影响项。讨论不启动设置写入或执行；小任务直接做，不为尚未需要的委派追问模型。

以质量为前提减少高价模型重复执行；Token、成本、耗时分开看，不保证均下降。

核对授权、验收、写权及进度，用户指定分工优先。主理人、执行者、复核者是本次任务的职责，不绑定特定平台、模型或Agent身份。恢复核实原执行者/产物状态，不重派已完成或进行中的工作。

- 小且直接可核对：主理人做，按影响验证。
- 边界清楚、资料可定位、可验收且值得交接：委派；复杂任务先拆分，不按编号或文件类型机械决定。
- 产品取舍、关键设计或故障原因未清：主理人先判断，可委派有边界的查证。

创建/调整分身时读[运行配置](references/runtime.md)；未经明确授权，分身不再派人。

交包：目标/完成标准、必要原始依据位置、写权（含所需测试等证据产物）、须保留行为/禁区、验收和回报证据。分清已确认要求、示例与未决项；示例不自动扩为通用规则，未决项不当作批准。相对路径须给出根目录。只传必要上下文。执行者负责实现、自测与范围内修复，可补必要检查，不降验收；长输出存文件，回报改动/结论、验收结果、证据位置及未完项。独立工具读取可批量处理。

独立复核按风险和项目要求安排，不固定凑角色或每测必派；给未参与实现者原要求、被验版本和证据，检查实际行为、边界及遗漏。主理人复核关键改动、证据和风险，负责验收/集成；证据充分不重复全做，缺失或矛盾时定向补查。区分实现、自测、独立复核、真实路径、正式合入；模拟通过不算真实业务通过。

失败带证据退修；越界、验收矛盾、同类返修无进展或需换模型时，主理人重新诊断，不无限重试或静默换档。无关可做部分继续，需用户取舍才问。

历史查询/更新沿用既有记录员，已有可靠依据不重查；主理人统一交包，避免重复上报。原任务记负责人/配置核验、证据、未完项和下一步；无记录员沿用项目记录方式，不因此另引记录Skill或台账。

评估效率/比较收益、问费用或项目要求计量时读[计量方法](references/measurement.md)，常规任务不额外核算。首次接入或迁移读[接入](references/project-setup.md)。
